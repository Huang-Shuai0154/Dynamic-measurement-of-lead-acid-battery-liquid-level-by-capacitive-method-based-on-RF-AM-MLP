# Dynamic-measurement-of-lead-acid-battery-liquid-level-by-capacitive-method-based-on-RF-AM-MLP
In order to eliminate the dynamic measurement error caused by the residual liquid film formation, an integrated learning algorithm combining random forest (RF), multi-layer perceptron (MLP) and attention mechanism (AM) is proposed.
There are seveal scripts in this repository in the "code" folder. The"Circuit_board_RF-AM-MLP.py","Circuit_board_MLP_only.py","Circuit_board_LSTM.py" and "Circuit_board_linear_static.py" are the training and testing procedures of "RF-AM-MLP","MLP", "static linear model" and "LSTM" respectively. And after training all the three models are saved to remain there parameters unchanged.The "Circuit_board_plot_figures_LSTM.py" compares the three models using different validation sets which are 30rpm,60rpm,100rpm and variable rates.And different figures are drawn to show the prediction results and error distribution of the three models. All the data appeared in the four scripts are provided accordingly in the "data" folder.
